审查日期：2026-11-14。此记录描述本次工作区修复与验证，不表示全仓逐行审查已经穷尽所有缺陷，也不保证不存在潜在问题。

## 已确认并修复

| 范围 | 原问题 | 修复 |
| --- | --- | --- |
| HTTP 请求边界 | 重复或异常 Content-Length、Transfer-Encoding、截断请求体可能产生不一致解释 | 明确拒绝不支持的请求分帧并核对实际长度 |
| JSON 输入 | 非有限数字及指数溢出可能进入业务配置；超长整数查询产生服务器错误 | 请求边界拒绝非法数字，参数错误转换为受控客户端错误 |
| 同源校验 | 仅比较 netloc，未核验协议和完整 Origin 格式；默认端口表示不一致 | 验证协议、主机、端口与 Origin 结构，保留可信反向代理规则 |
| 登录导航 | 未登录访问深层页面后丢失原路径、查询参数或页内位置 | 前后端保留 next，前端限制为应用内相对路径并排除登录循环 |
| 前端请求 | Headers 实例的请求头丢失；无效成功响应被当成有效数据；读取响应时取消被吞掉 | 使用标准 Headers，拒绝无效 JSON 对象响应，传播取消错误 |
| 搜索流 | 不兼容 CRLF 事件分隔；终止事件后仍等待连接；异常事件数据缺少形状校验 | 修正 SSE 解析并在终止事件后释放 reader |
| 播放器状态 | 损坏的 sessionStorage 可污染播放状态；其他页面会启动隐藏播放解析 | 校验存储结构，按可见状态启动播放 |
| 加载架构 | 全局播放工作区静态引用页面，使原有路由懒加载失效 | 播放页面延迟加载，时间格式化函数移入独立工具模块 |
| 播放进度 | 拖回零秒后不保存，下一次恢复旧进度 | 允许保存零秒，拒绝无效时间 |
| 键盘操作 | 控件取得焦点后仍会自动隐藏 | 焦点位于播放器控件时保持可见与可操作 |
| 设置契约 | 未登录认证状态响应省略敏感字段，前端类型却要求其存在 | 对齐响应类型并保护可选字段访问 |
| 整理规则 | 界面上下移动只改数组顺序，后端仍按旧优先级执行；重复规则 ID 含义不明确 | 移动时同步优先级，服务端拒绝重复 ID |
| 配置验证 | sites 类型或 ID 非法可能引发未受控错误 | 在读取、合并原配置前验证 |
| 外部地址校验 | 组播及部分 IPv6 内嵌私网地址可能通过公网检查 | 拒绝组播并检查 IPv4 映射及 6to4 内嵌地址 |
| 下载续传 | 仅凭相同 URL、长度或弱 ETag 续传，可能拼接新旧文件 | 缺少可靠验证信息时重新下载，不冒险拼接 |
| 显示格式 | 小于 1 字节的速度可能产生负单位索引 | 限制单位索引下界 |
| 依赖安全 | npm 审计报告 10 个受影响包；Python 锁中三个包存在已知漏洞 | 更新 Vite、Vitest 与相关锁依赖；更新 Pillow、SoupSieve 并重新解析生产锁闭包 |
| 生产锁工具 | 自制 Python 版本解析不接受补丁号约束 | 使用标准版本约束解析；最低 Python 改为 3.11.5，同步安装说明 |
| 翻译维护 | 每种语言有 168 个未引用条目 | 删除失效条目并补齐新错误提示的七种语言翻译 |
| 构建与备份排除 | 实际生成的 .bak.时间戳文件未被现有规则覆盖 | Git 与 Docker 上下文补充排除，排除 Vite 缓存 |

## 剩余修复项已处理

- 将管理页面样式从全局样式移到使用它们的组件，保留原有响应式规则及同一组规则的顺序。首屏 CSS 从 133.46 kB 降至 89.76 kB；已保存的桌面、手机对照截图像素差为零。
- 普通视频不再下载 HLS 引擎。原生 HLS 且无 MediaSource 的浏览器直接使用原生播放；支持 MediaSource 的浏览器保留原有 HLS 引擎与清晰度选择，不能只为了省包而删减功能。
- 预算工具现在计算首屏静态依赖闭包，防止 vendor 拆包漏计。入口 JS 350 KiB、首屏 CSS 100 KiB、普通懒加载代码 75 KiB、语言包 256 KiB、初始总量 450 KiB 的原阈值均未提高。
- **预算分类有一项明确调整：** 完整 HLS 第三方引擎不再套用普通页面 75 KiB 限制，改为 512 KiB 媒体依赖闭包总预算，并禁止进入首屏。这是保留完整媒体能力的独立预算，不代表把 HLS 引擎缩小到了 75 KiB，也没有为过检查将它人为切成小文件。
- 最终预算报告通过：入口 JS 355187 字节、首屏 CSS 89759 字节、初始总量 444946 字节、最大普通懒加载代码 54981 字节、最大语言包 216404 字节、HLS 引擎 523156 字节。
