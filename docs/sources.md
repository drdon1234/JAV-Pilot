# 来源说明

[返回 README](../README.md)

JAV Pilot 从下列站点获取资料、磁链和视频。外部站点会改版、限制地区或要求人机验证，JAV Pilot 无法保证它们在任何网络环境下都可用；各站点当前能否访问，以“站点 → 站点诊断”的结果为准。

## 来源一览

| 来源 | 提供 | 默认 | 说明 |
| --- | --- | --- | --- |
| JavBus | 资料、磁链、截图 | 启用 | |
| JavDB | 资料、磁链 | 启用 | 普通请求失败时改用内置浏览器 |
| FC2 | FC2 作品资料 | 启用 | 以官方页面核对作品身份，官方下架时使用备用来源 |
| JableTV、SupJav | 视频下载 | 启用 | |
| MissAV | 视频下载、作品简介 | 启用 | 使用内置浏览器及其独立的浏览器数据 |
| FANZA、MGS、AVBase | 关键词搜索与作品资料 | 关闭 | 不提供磁链；常受地区限制或访问验证影响 |
| FC2DB、JAVTEN | FC2 作品资料 | 关闭 | 只接受带 `FC2` 前缀的完整番号，不支持关键词搜索 |
| Sukebei、Tokyo Toshokan | 种子搜索 | 关闭 | 需要 Torznab 服务，见[种子索引](indexers.md) |
| KissJAV、JAV-NONI | 查找视频资源 | 关闭 | 只在搜索中列出，不参与自动下载 |

来源可以在“站点”页面启用、停用和调整优先级。

## 结果如何合并

- 同一番号的资料跨站合并为一条结果，每个字段都保留来源；没有合法番号的条目按来源分别显示。
- 磁链按 info hash 去重，保留每个来源报告的大小和做种数。做种数只是站点的说法，能否下载以 qBittorrent 实际情况为准。
- 一个站点出错不影响其他站点的结果。站点出错、需要验证或被地区限制时会显示为错误，不会当作“没有找到作品”。
- 种子索引只为已有作品补充磁链，不决定作品标题；关闭“解析磁链”时不查询种子索引。

## Web 下载如何选择来源

Web 下载按“站点”中的优先级依次尝试 JableTV、SupJav、MissAV。在某个站点找到作品页面并不代表一定能下载：后台还会核对番号、版本（原片、中文字幕、无码）和实际画质，不满足时继续尝试下一个站点。全部失败的任务记录在“下载 → 失败归档”。

## FC2 番号

FC2 作品必须带 `FC2` 前缀。`FC2-PPV-<编号>` 和 `FC2-<编号>` 指同一部作品；纯数字不会被当作 FC2 番号。

## 站点地址变化时

站点换了域名时，可以在“站点”中修改该站点的“站点域名”；页面结构变化需要等待 JAV Pilot 更新。视频文件所在的媒体服务器地址受安全限制，只能通过版本更新调整。
